# THE ARCHIVE — Render Extractor API

## Deploy on Render (Free Web Service)
1. Ei `render-extractor-api` folder-er `package.json` ar `server.js` file-gulo ekta GitHub repository-te push korun (ba Render-e connect korun).
2. Render Dashboard-e **New + -> Web Service** click kore repo select korun:
   - **Runtime:** Node
   - **Build Command:** `npm install`
   - **Start Command:** `node server.js`
3. Deploy hoye gele Render apnake ekta URL debe, jemon:
   `https://the-archive-extractor.onrender.com`
4. Sei URL-ta InfinityFree website-er `api/config.php` file-er `RENDER_EXTRACTOR_URL`-e bosiye din.
